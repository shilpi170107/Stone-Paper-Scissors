# 🎮 Stone Paper & Scissors Game

A simple and interactive **Stone Paper & Scissors** game built using **HTML, CSS, and JavaScript**.

Play against the computer, choose your move, and see who wins! The game keeps track of both the **player's score** and the **computer's score**.

## 🌐 Live Demo

🎮 **Play the game here:**  
https://stone-paper-scissors-one-iota.vercel.app/

## ✨ Features

- 🪨 Choose **Stone**
- 📄 Choose **Paper**
- ✂️ Choose **Scissors**
- 🤖 Play against the computer
- 📊 Real-time score tracking
- 🏆 Displays the game result after every move
- 🔄 Reset Game option to start a new game
- 🎨 Simple and attractive user interface

## 🛠️ Technologies Used

- **HTML** – For the structure of the game
- **CSS** – For styling and designing the user interface
- **JavaScript** – For implementing the game logic and interactivity

## 🎯 How to Play

1. Choose either **Stone, Paper, or Scissors**.
2. The computer will randomly select its move.
3. The winner is decided based on the following rules:
   - 🪨 Stone beats ✂️ Scissors
   - ✂️ Scissors beats 📄 Paper
   - 📄 Paper beats 🪨 Stone
4. The scores are updated after every round.
5. Click **Reset Game** to start a new game.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in your browser.
4. Start playing and have fun! 🎉
